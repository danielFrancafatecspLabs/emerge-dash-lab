Blocked Time

Média de dias bloqueados dos experimentos concluídos, calculado via changelog:

📋 Algoritmo de Blocked Time
  1. Para cada Epic concluído, varre o changelog cronologicamente
  2. Quando motivoBloqueio passa de vazio → preenchido: marca início do bloqueio
  3. Quando passa de preenchido → vazio: soma os dias ao total bloqueado
  4. Ao final: blockedTimeDias = SUM(dias bloqueados) ÷ qtd de Epics com bloqueio
  5. blockedTimePct = (blockedTimeDias ÷ mediaTotalDias) × 100
